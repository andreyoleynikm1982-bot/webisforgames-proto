## About

A classic arcade game reimagined with modern web technologies. Control your spaceship and defend Earth from waves of alien invaders.

## Features

- Smooth animations powered by Canvas API
- Responsive controls for both keyboard and touch
- Progressive difficulty levels
- Classic arcade sound effects
- High score tracking

## Technologies Used

- HTML5 Canvas
- Web Audio API
- Vanilla JavaScript

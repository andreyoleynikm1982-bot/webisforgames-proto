## About

High-speed racing game with stunning graphics and realistic physics. Choose from multiple vehicles, race on various tracks, and compete against AI opponents.

## Features

- Multiple vehicles and tracks
- Realistic physics engine
- Power-ups and special abilities
- Time trial mode
- Multiplayer support via WebSockets
- Stunning 3D graphics with WebGL

## Technologies Used

- WebGL for 3D graphics
- Physics engine (custom built)
- WebSockets for multiplayer
- Gamepad API support

## About

An engaging puzzle game that challenges your logic and problem-solving skills. Match colors, solve patterns, and progress through hundreds of increasingly complex levels.

## Features

- Hundreds of unique puzzle levels
- Smooth animations with WebGL
- Hint system for difficult puzzles
- Progress saving with LocalStorage
- Relaxing background music

## Technologies Used

- WebGL for rendering
- Web Audio API
- LocalStorage for saves
